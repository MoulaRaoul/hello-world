# Jeu de drapeaux

Petit projet personnel d'initiation au développement web, réalisé avec HTML, CSS et JavaScript.

Le fichier principal est [`index.html`](index.html). Pour essayer le jeu, téléchargez ou clonez le dépôt, puis ouvrez ce fichier dans un navigateur.

## Statut

**Projet d'apprentissage.** Ce dépôt est conservé comme trace de progression en programmation web. Il ne représente pas le portfolio scientifique principal.
